## 🌟 نبذة عن المشروع

هذا المشروع عبارة عن مبادرة تعليمية رقمية (مبادرة أ.فوزية كمال) تهدف إلى توفير بيئة تحاكي الاختبارات ال لتقييم مهارات الطلاب في القراءة. يتيح الموقع للطلاب إجراء اختبارات تفاعلية على نصوص قراءة متنوعة، مع تقديم تغذية راجعة فورية وتحليلات للأداء.

كما يوفر النظام لوحات تحكم مخصصة للمعلمين والإداريين لمتابعة تقدم الطلاب وإدارة المحتوى التعليمي.

## ✨ المميزات الرئيسية

### 👨‍🎓 للطلاب

- **واجهة اختبار تفاعلية**: تصميم مريح وجذاب يشجع على القراءة والتركيز.
- **تنوع النصوص**: فقرات قراءة متعددة المستويات (أدبية وعلمية).
- **تقييم فوري**: الحصول على النتيجة وتحليل الإجابات مباشرة بعد الانتهاء.
- **مؤقت اختياري**: إمكانية خوض الاختبار بوقت محدد أو مفتوح لتدريب الطلاب.
- **تصميم متجاوب**: تجربة مستخدم ممتازة على الهواتف والأجهزة اللوحية.

### 👨‍🏫 للمعلمين والمشرفين

- **إدارة الاختبارات**: إنشاء وتعديل الاختبارات والأسئلة بسهولة.
- **متابعة الطلاب**: الاطلاع على نتائج الطلاب ومحاولاتهم بالتفصيل.
- **إدارة الفصول**: تنظيم الطلاب في مجموعات وعرض إحصائيات الأداء.
- **لوحة تحكم شاملة**: أدوات تحكم لصلاحيات الوصول وإدارة البيانات.

## 🛠 التقنيات المستخدمة

تم بناء المشروع باستخدام مجموعة من التقنيات الحديثة لضمان الأداء العالي وسهولة الاستخدام وصيانة الكود:

- **الواجهة الأمامية (Frontend)**:

  - ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white) **HTML5**: لبناء هيكلية الصفحات الدلالية.
  - ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white) **TailwindCSS**: إطار عمل CSS لتصميم واجهات عصرية ومتجاوبة بسرعة وكفاءة.
  - ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black) **Vanilla JavaScript (ES6+)**: منطق التطبيق التفاعلي وإدارة الحالة بدون مكتبات ثقيلة.

- **الواجهة الخلفية وقاعدة البيانات (Backend & DB)**:
  - ![Supabase](https://img.shields.io/badge/Supabase-3ECF8E?style=flat-square&logo=supabase&logoColor=white) **Supabase**: منصة backend-as-a-service توفر:
    - **Authentication**: نظام تسجيل دخول آمن وإدارة صلاحيات المستخدمين.
    - **PostgreSQL Database**: قاعدة بيانات علائقية قوية لتخزين البيانات.
    - **Row Level Security (RLS)**: حماية البيانات وعزلها حسب أدوار المستخدمين.

## 🚀 تشغيل المشروع محلياً

لتشغيل نسخة من المشروع على جهازك، اتبع الخطوات التالية:

### المتطلبات المسبقة

- متصفح ويب حديث (Chrome, Edge, Firefox).
- حساب على [Supabase](https://supabase.com).

### خطوات التثبيت

1. **نسخ المستودع**:

   ```bash
   git clone https://github.com/a7-m/Fawzia.git
   cd Fawzia
   ```

2. **إعداد قاعدة البيانات**:

   - قم بإنشاء مشروع جديد على Supabase.
   - انتقل إلى SQL Editor في لوحة تحكم Supabase.
   - انسخ محتوى الملف `rebuild_database.sql` وقم بتنفيذه لبناء الجداول والصلاحيات.

3. **ربط المشروع**:

   - قم بإنشاء ملف إعدادات (أو عدل الملف الموجود في `js/config.js` أو `js/supabase-client.js`) وأضف مفاتيح الربط الخاصة بمشروعك:
     ```javascript
     const SUPABASE_URL = "YOUR_SUPABASE_URL";
     const SUPABASE_KEY = "YOUR_SUPABASE_ANON_KEY";
     ```

4. **التشغيل**:
   - يمكنك استخدام إضافة "Live Server" في VS Code لتشغيل الملف `index.html`.
   - أو تشغيل خادم محلي بسيط باستخدام Python:
     ```bash
     python -m http.server
     ```
   - افتح المتصفح على العنوان `http://localhost:8000`.
